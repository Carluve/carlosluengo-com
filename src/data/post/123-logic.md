## Overview

**1-2-3 Logic** is a web game that builds logical thinking and visual reasoning in early learners through short, colourful, emoji-based puzzles.

The interface is clean and the challenges get harder step by step. Children complete visual patterns, sequences and logic problems that ask them to observe, predict and reason.

## Key features

- **Pattern recognition** with emojis, shapes and colours
- **Progressive challenges** of increasing complexity
- **Local progress tracking** for self-paced learning
- **Minimal, accessible design** focused on clarity
- **i18n-ready** for several languages
- **Responsive** on desktop and mobile
