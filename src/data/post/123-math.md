**Project type:** Educational web game
**Technologies:** React, Tailwind CSS, Vite, i18n, LocalStorage
**Role:** Product design, frontend development, user experience

## Overview

**1-2-3 Math** is an educational web game for young learners. It strengthens arithmetic skills through quick, visual and interactive challenges.

Children practise addition and subtraction in a timed environment and pick the correct answer from a set of colourful options. Multiplication and division are next. The aim is **fast recall**, **engagement** and **confidence** with basic maths facts.

## Key features

- **Randomised operations** by difficulty level (Easy, Normal, Hard)
- **Visual countdown timer** with a colour-coded progress bar
- **Session progress** saved locally in the browser
- **i18n** for several languages
- **Responsive layout** for tablets, desktops and phones
- **A fixed number of exercises per session**, so practice stays short and focused
