Titular del sitio: Carlos Luengo Vera. Dominio previsto: carlosluengo.com. El sitio se publica como páginas estáticas.

## Qué no hace este sitio

No hay formulario de contacto, boletín ni área de usuario. No se instalan herramientas de analítica ni píxeles de seguimiento. No se venden datos personales ni se ceden a terceros con fines comerciales.

La correspondencia se atiende por [LinkedIn](https://www.linkedin.com/in/carlosluengo), fuera de este sitio.

## Preferencia de tema

El selector de tema claro u oscuro puede guardar la elección en el almacenamiento local del navegador (`localStorage`). Esa preferencia no se envía al servidor de este sitio y puede borrarse desde el propio navegador.

## Alojamiento

La publicación estática se realiza en Cloudflare Pages. El proveedor puede tratar datos técnicos de conexión (por ejemplo, dirección IP o agente de usuario) para entregar el sitio y proteger la red. Ese tratamiento se rige por la [política de privacidad de Cloudflare](https://www.cloudflare.com/privacypolicy/).

## Enlaces externos

LinkedIn, GitHub, Google Scholar, arXiv y el resto de sitios enlazados aplican sus propias condiciones. Al seguir un enlace se abandona este sitio.

## Ejercicio de derechos

No se conserva en este sitio un fichero de datos personales de quienes lo visitan. Para una cuestión relativa a esta página, el canal es el perfil de LinkedIn indicado arriba.
